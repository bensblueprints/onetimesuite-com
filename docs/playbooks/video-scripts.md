# Video Scripts — 60-Second Shorts

**What this is:** the 60-second batch template for YouTube Shorts/TikTok/Reels, 10 fully written scripts for flagship apps, the thumbnail spec, and the multi-platform distribution table.
**How to use it:** batch-record 10 per session (one afternoon/week). All prices match the README table and competitor yearly costs from the product data — re-verify competitor prices on their live pricing pages before recording, and say prices on camera exactly as written.

---

## The 60-second template

| Time | Beat | What to do |
|---|---|---|
| 0–3s | Hook | The price contrast, said fast: "Loom costs you $180 a year. This costs $29. Once." |
| 3–15s | Problem | What the subscription does wrong: rent, caps, uploads, accounts. One idea, not three. |
| 15–45s | Screen demo | Real screen recording of the actual app. Show the one feature that proves the claim. No filler clicks. |
| 45–55s | Proof | The honest closer: free MIT MVP on GitHub, runs locally/self-hosted, pay-once model. |
| 55–60s | CTA | "Link in bio" / "onetimesuite.com/<slug>/" + "free version on GitHub." |

Rules: real app footage only (no mockups), on-screen price line visible from 15s onward, "Day [N]/100" top corner when part of the build series, never say "limited time" — the +$1/sale bundle counter is the only urgency and it's real.

## The 10 scripts

### 1. BloomRecorder ($29 once vs Loom ~$180/yr)

- **0–3 Hook:** "Loom charges you $180 a year to record your own screen. I replaced it for $29 — once."
- **3–15 Problem:** "Every Loom recording lives on Loom's servers, behind a Loom account, with plan limits on length. Stop paying and the links rot."
- **15–45 Demo:** Screen recording: open BloomRecorder → pick screen + camera from the live-thumbnail picker → record 5 seconds → stop from the floating pill → trim the ends → export MP4. On-screen: "100% local — zero accounts, zero uploads."
- **45–55 Proof:** "Unlimited length, MP4 and GIF export, and every file lands in a folder on your own disk. The core is free and MIT-licensed on GitHub."
- **55–60 CTA:** "BloomRecorder, $29 once — onetimesuite.com/bloomrecorder/. Free MVP linked too."

## Thumbnail template spec

Consistent across every Short cover / YouTube thumbnail so the series is recognizable:

| Element | Spec |
|---|---|
| Left half | Competitor logo on neutral background, **red X** over it |
| Right half | App icon (from the landing page) with **green check** |
| Bottom strip | Price line: "$[competitor yearly]/yr → $[app price] once" (e.g. "$180/yr → $29 once") |
| Top corner | "Day [N]/100" badge during the 100-day build |
| Canvas | 1080×1920 (vertical) for Shorts covers; export a 1280×720 crop for YouTube thumbnail slots |
| Rules | Logos at clearly legible size, no altered competitor logos beyond the red X, prices must match the video exactly |

## Multi-platform distribution table

| Platform | Format | Length | Adaptation |
|---|---|---|---|
| YouTube Shorts | 1080×1920, vertical | ≤60s | Native upload; title = "[$App] vs [Competitor]: $[price] once, not $[yearly]/yr"; link app page in description; pinned comment with the GitHub MVP link |
| TikTok | 1080×1920, vertical | ≤60s | Same file; put the price contrast in the first on-screen caption; link via bio |
| Instagram Reels | 1080×1920, vertical | ≤60s | Same file; cover image per thumbnail spec; caption leads with the hook line |
| LinkedIn | 1080×1920 or 1:1 crop | ≤60s | Native upload (not a YouTube link); first line of the post is the hook; add 2–3 lines of the behind-the-build context |
| X | 1080×1920 or 16:9 crop | ≤60s (or 2:20 max) | Native upload; post text = the subscription-roast version of the hook; reply to your own post with the app link (links in main post suppress reach) |

**Cadence:** max 1 Short/day/platform; batch of 10 covers ~2 weeks per platform. Cross-post the same file — no platform-specific re-edits except the crops above.
