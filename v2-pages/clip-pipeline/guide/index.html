1. Quick start

Windows: run the installer and follow the wizard. macOS: open the DMG, drag Clip Pipeline to Applications, then right-click → Open the first time (the build is unsigned).

The installer is self-contained: ffmpeg, Node, yt-dlp, and a portable faster-whisper engine are inside. You do not need Python, ffmpeg, or Node installed separately.

  1. Install and launch. A new job is created automatically.
  2. Get a free Groq API key. The full workflow needs one for script rewriting and AI moment scoring. Groq setup → Skip it only if you want the no-AI fallbacks.
  3. Paste a video URL, or click Open Local Video to work on a file you already have.
  4. Click Run All for the full pipeline, or run individual steps. Steps you do not want can be skipped.
  5. Find the result in the job folder, or in the local export folder you choose in Settings.

Get a free Groq API key Start here

The full workflow needs a free Groq API key. Script rewriting and YouTube Clipper’s AI viral-moment scoring both use Groq. Without a key, Clip Pipeline falls back to local Whisper, the transcript as the script, the built-in system voice, and fixed-length clips — usable, but not the full intended workflow.

Free tier Groq’s free tier is enough to start and does not require a credit card. Rate limits apply; the app can rotate extra keys if you add them later.

1. Create an account

Open console.groq.com. Click Continue with Google, Continue with GitHub, Continue with SSO, or enter your email and click Continue with email. Complete the verification step.

2. Open the API Keys page

After signing in, open console.groq.com/keys, or choose API Keys in the top navigation.

3. Create the key

  1. Click Create API Key.
  2. Set Display Name to Clip Pipeline.
  3. Leave Expiration at No expiration, or choose a rotation period you prefer.
  4. Click Create. Copy the gsk_… key immediately — Groq shows it only once.

4. Paste it into Clip Pipeline

Open Clip Pipeline → Settings → Groq API key, paste the key, then click Save Settings. The field is at the top of Settings; see the API keys section. If you have more than one free key, add the extras under Extra Groq keys for automatic rotation.

Keep it secret The key is stored in the app settings file. Do not share it or commit it. If it leaks, revoke it on the Groq API Keys page and create a new one.

With the key in place, Rewrite Script and Find Viral Moments work. If you hit a rate limit, add another free key; the pipeline rotates to it automatically.

3. The pipeline

StepWhat it doesNeeds
1. Download VideoDownloads the source, merges video + audio, saves source.mp4.Bundled yt-dlp + Node
2. Extract CaptionsTranscribes the original audio with word timestamps.Groq key or local Whisper
3. Rewrite ScriptRewrites the transcript into a tighter short-form script.Groq key; otherwise the transcript is used
4. Generate VoiceSpeaks the script with ElevenLabs, a local Qwen voice, or the built-in system voice.ElevenLabs key, Qwen engine, or nothing
5. Remove Original CaptionsBlurs, delogos or crops the caption band using ffmpeg.Bundled ffmpeg only
6. Analyze ScenesFinds scenes, crossfades and zoom moves.Optional VSR engine
7. Remove Captions & Recreate ImagesRebuilds clean scene backgrounds and saves stills.Optional VSR engine
8. Regenerate Images (AI)Creates new artwork per scene.Optional ComfyUI engine
9. Rebuild VideoRebuilds the video from clean images with push-ins and crossfades.Optional VSR engine
10. Assemble with New VoiceMerges the clean video and the new voiceover, retiming if needed.Bundled ffmpeg
11. Attach New CaptionsBurns word-synced captions onto the final clip.Groq timestamps or local Whisper
Skip tip The heavy VSR/ComfyUI steps are pre-skipped when those engines are not installed. The core workflow still completes through steps 1–5, 10 and 11.

Transcript and Script boxes let you paste your own text. Paste a transcript and skip Extract Captions; paste a script and skip Rewrite Script; or skip Rewrite with a transcript present and the transcript becomes the spoken script.

5. YouTube Clipper

ControlWhat it does
Video URLThe YouTube video to clip. The title is fetched without an API key.
Clip length15s, 30s or 60s. AI moments are clamped to this length; the fixed fallback uses it exactly.
Clips1–30. The AI is asked for this many moments; remaining slots are filled with fixed clips if it returns fewer.
Burn captionsOn: word captions are burned into both outputs. Off: clean exports with no captions.

The clipper engine shows four stages: Download Video, Transcribe, Find Viral Moments, and Cut Clips. Qwen is tried first for moment scoring; other models are fallbacks. If AI finds nothing, it cuts fixed-length clips rather than failing.

Find viral videos to clip (collapsible at the bottom) needs a YouTube Data API key. It is optional; pasting a URL works without it.

6. No-AI workflow

Clip Pipeline has a no-AI fallback path: the bundled local Whisper engine and the built-in system voice cover transcription and voiceover. These are fallbacks, not the full workflow — for script rewriting and AI viral-moment scoring, add the free Groq API key.

  1. Transcription: with no Groq key, Extract Captions switches to local Whisper automatically. Download the model once; later runs use the cache.
  2. Script: Rewrite Script falls back to the transcript when no Groq key is set. You can also paste your own script and skip Rewrite.
  3. Voice: choose Built-in system voice in Settings. No key, no account; the OS voice speaks the script.
  4. Captions: Attach New Captions uses local Whisper word timestamps when Groq is unavailable.
  5. YouTube Clipper: no Groq key means fixed-length clip selection. No YouTube API key means use a pasted URL instead of discovery.
  6. Caption removal: step 5 uses ffmpeg blur/delogo/crop. No VSR or ComfyUI needed.
What is optional Groq, ElevenLabs, the YouTube Data API key, VSR (GPU rebuild/inpaint), ComfyUI (AI image regeneration), and rclone/Google Drive. The app skips the heavy steps automatically when their engines are missing.

Common issues

SymptomFix
App still shows an old buildClose every Clip Pipeline window and relaunch. A running window keeps the old code until restarted.
Local transcription is slow the first timeThe model downloads once. Use tiny or small for speed; watch the Activity Log for progress.
YouTube download fails (403)Use the Update downloader banner when it appears; the app checks yt-dlp on launch. For logged-in videos, import cookies.
Groq model_not_foundThe configured model was retired. The app migrates to a current default; moment scoring also tries fallback models.
Groq json_validate_failedThe model returned malformed JSON. The clipper retries and falls back to fixed-length clips.
Rebuild or AI Images failsThose steps need VSR/ComfyUI, which are not bundled. Leave them skipped, or point CLIP_PIPELINE_VSR_DIR / CLIP_PIPELINE_COMFY_DIR at your installs.
macOS says the app is damagedThe build is unsigned. Right-click the app → Open the first time; if needed, remove the quarantine flag in Finder.
