Vapi tool webhook

In Vapi, create a Bearer credential named OneTimeSuite Website Builder, paste this token, and select it on start_website_build. Keep this token private.

The webhook requires its server-side Bearer credential. The tool definition contains no secrets. Builds require consent and a confirmed calendar event 24–48 hours ahead. Web form submissions wait for qualification.
