# Content Calendar — 30 Days

**What this is:** a 30-day posting grid plus the reusable formulas behind it: X/LinkedIn post types, the YouTube Shorts batch plan, the WhatsApp weekly rhythm, and the build-day content multiplier.
**How to use it:** the grid loops — after day 30, start over with fresh apps and current prices. Replace every `[bracket]` with a real value. All prices below match the README table; re-verify before posting.

---

## X / LinkedIn post formulas (5 types, rotated)

### 1. App drop
**Formula:** New app name + what it replaces + one feature + price vs competitor yearly cost + link.
> **Fill-in example:** "App [N] of 102: **Bookslot** — the Calendly you actually own. Timezone-correct booking pages with email + ICS invites, self-hosted. Calendly is ~$120/yr. Bookslot is $39, once. Free MIT MVP on GitHub. onetimesuite.com/bookslot/"

### 2. Subscription roast
**Formula:** One competitor's real yearly cost (with "as of [date]") + the absurdity framed honestly + the alternative. Never misquote.
> **Fill-in example:** "Typeform charges $29/mo for forms — that's ~$348/yr, as of [date], to ask people questions. Formforge does Typeform-style forms with unlimited responses and CSV export, self-hosted, for $39. Once. The roast writes itself."

### 3. Behind-the-build
**Formula:** What got built/fixed today + one real technical or business detail + what's next.
> **Fill-in example:** "Day [N]/100. Shipped [app] this morning, then spent two hours fixing [real problem — e.g. the timezone bug in Bookslot's ICS invites]. Tomorrow: [next app]. 65 of 102 live."

### 4. User win
**Formula:** Real member outcome (from WhatsApp, with permission) + the app + the math. No fabricated quotes.
> **Fill-in example:** "[Name/initials, with permission] replaced Loom (~$180/yr) with BloomRecorder ($29 once) and [real detail — e.g. 'records client walkthroughs daily, nothing leaves their machine']. [If no real user story exists yet, skip this slot and post an extra behind-the-build.]"

### 5. Event recap
**Formula:** City + one honest takeaway + the tools people said they're ditching + link to the recap.
> **Fill-in example:** "Back from [Event] in [City]. Heard the same thing [N] times: 'I'm paying for tools I forgot I had.' Most-ditched: Calendly, Loom, Typeform. Recap + what I demoed: onetimesuite.com/events/[slug]/"

## YouTube Shorts batch plan

- **Cadence:** one afternoon per week, **10 Shorts per session**.
- **Prep (30 min):** pick 10 apps, pull scripts from `video-scripts.md` (or write new ones from the 60-second template), queue the apps on the demo machine.
- **Record (2 hrs):** screen-record each demo segment back-to-back, then record all 10 hooks/CTAs to camera in one setup. ~12 min per Short.
- **Edit (1.5 hrs):** template edit — hook text overlay, demo speed-ramp, price line, thumbnail per the spec in `video-scripts.md`.
- **Schedule (30 min):** 1/day on YouTube; cross-post per the distribution table in `video-scripts.md`.
- Output per month: ~40 Shorts from 4 afternoons.

## WhatsApp weekly rhythm

**Rule: 80/20 value-to-ask.** Roughly four of five messages teach, update, or entertain; at most one in five asks for anything (webinar attendance, purchase, share).

| Day | Slot | Content |
|---|---|---|
| Mon | App drop voice note | 60–90 sec voice note: this week's app, what it replaces, price vs competitor, one tip for using it |
| Tue | Fix / update | What got fixed or improved this week — honest changelog, including what broke |
| Wed | Member win | A real member's result (with permission) or a useful tip from the group |
| Thu | Roadmap poll | Poll: which of these [3 real upcoming apps] should ship first |
| Fri | Webinar reminder | The one "ask" slot: webinar link + what they'll see in 12 minutes |
| Sat | Casual | Founder-life post: conference photo, build setup, no pitch |
| Sun | Event preview/recap | Next event or last event recap; QR/webinar link for newcomers |
