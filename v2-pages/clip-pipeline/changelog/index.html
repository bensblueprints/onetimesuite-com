Clip Pipeline v1.0.0

July 19, 2026 View on GitHub →

Windows installer and macOS Apple Silicon (arm64) DMG for Clip Pipeline.

Self-contained build:

  • Bundled ffmpeg (with libass), Node, yt-dlp and a portable faster-whisper engine. No separate Python, ffmpeg or Node install.
  • Local Whisper runs on CPU or an NVIDIA GPU. The model downloads once on first use (default small ~466 MB; tiny ~75 MB, medium ~1.5 GB, large-v3 ~3 GB).
  • Per-step Skip buttons: exclude any step from Run All; manual Run still works.
  • Exports: choose a local export folder in Settings; finished clips are copied there automatically. Google Drive export is coming soon.
  • YouTube Clipper:
  • 1–30 clips per run and 15s / 30s / 60s clip length.
  • Burn captions on/off, caption colour picker, and vertical caption position slider.
  • Qwen-first Groq moment scoring with automatic model fallback; fixed-length fallback if AI finds nothing.
  • No-AI path: transcript-as-script, local caption timing, built-in system voice, and heuristic clip selection.
  • Heavy optional engines (VSR rebuild/inpaint, ComfyUI image regeneration) are skipped automatically when not installed.

Optional keys: Groq for script rewriting and viral scoring, ElevenLabs for cloud voices, YouTube Data API for channel discovery.

Bundled ffmpeg is GPL; source and build information at ffmpeg.org.

The macOS build is unsigned. Right-click the app and choose Open the first time.
